# Deployment

```bash
cd rodolfo-portfolio-command-center-v0.6.9-dev-page-rc
bash scripts/publish.sh https://github.com/USERNAME/REPOSITORY.git "Publish developer portfolio"
```

Then open GitHub **Settings → Pages** and select **GitHub Actions**.

Before commercial launch:

- replace commercial and diagnosis URLs;
- configure or disable WhatsApp and Telegram;
- add final absolute `og:url` and `og:image`;
- decide whether analytics and a privacy notice are needed.
