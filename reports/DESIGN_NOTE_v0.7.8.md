# Design Note · v0.7.8 Signature Mark

The accepted mark is now treated as a signature rather than ornament.

It appears at five identity anchors:

1. Header brand lockup
2. Desktop consulting dossier
3. Tablet identity band
4. Mobile profile card
5. Footer signature

All placements use the same transparent SVG. The mark is never placed inside a new badge, circle, tile, or glowing container because its own technical perimeter already supplies the enclosure. No new motion was added.
